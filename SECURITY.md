# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Use GitHub's private reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers can see the report.

Include the affected component and version, the steps to reproduce, and the impact you expect. This applies to the specification, the example and every other repository of the [OAAX-standard organization](https://github.com/OAAX-standard).
