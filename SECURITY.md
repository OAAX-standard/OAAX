# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Use GitHub's private reporting instead: open this repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers can see the report.

Include the affected component and version, the steps to reproduce, and the impact you expect.

For a runtime or toolchain repository of the [OAAX-standard organization](https://github.com/OAAX-standard), report in that repository's Security tab. If it does not offer **Report a vulnerability**, open an issue that only asks for a private contact, without any details of the vulnerability.
