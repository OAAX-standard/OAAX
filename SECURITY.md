# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Use GitHub's private reporting instead: open the **Security** tab of the affected repository and choose **Report a vulnerability**. Only the maintainers can see the report.

If you cannot use it, email **security@oaax.org** with the same details.

Include the affected component and version, the steps to reproduce, and the impact you expect.
